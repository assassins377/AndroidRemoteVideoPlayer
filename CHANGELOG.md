# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]
### Добавлено
- Библиотека: звёздочка «Избранное» у каждого видео и долгое нажатие → карточка с «Не тот фильм?», скачиванием и трейлером.
- Поиск: подсказки названий при вводе (серии сгруппированы по сериалу), недавние запросы, точная фраза в кавычках, кнопка очистки.
- Jellyfin: новый тип сервера — вход по логину/паролю, библиотеки как папки, прямое воспроизведение, синхронизация отметок «просмотрено» в обе стороны. Plex пока не поддерживается.
- Загрузки на устройство (WorkManager): фоновая загрузка с уведомлением и прогрессом, докачка после обрыва, повтор при ошибке, экран «Загрузки» с местом на диске и удалением; скачанное видео играет без сети.
- Трансляция на ТВ: Chromecast (Default Media Receiver) и DLNA/UPnP-телевизоры; видео с SMB/WebDAV/HTTP раздаётся телефоном через встроенный локальный HTTP-прокси с поддержкой перемотки.
- Android TV: значок в лаунчере TV (баннер), управление пультом в плеере (←/→ перемотка, OK пауза, ↑/↓ панель), сетка постеров и рамка фокуса, отступы под overscan.
- Карточка фильма: слоган, жанры, длительность, описание, актёры с фото и кнопка трейлера (YouTube) из TMDB.
- Кадры из видео вместо постера: если TMDB не нашёл фильм, берётся кадр примерно на 10 % длительности (потоково, без скачивания файла), кэшируется; переключатель в настройках.
- Задержка внешних субтитров (SRT/VTT/ASS) в плеере: шаги ±0,1/±0,5 с, запоминается для каждого файла; по умолчанию берётся из настроек.
- Сериалы: группировка серий (S01E02, 1x02, «Сезон 1/Серия 04», папки Season N), экран сезонов и серий, постеры TMDB TV, отметки «просмотрено» (автоматически после 90 %), автозапуск следующей серии с обратным отсчётом 10 с.
- Экран «Библиотека»: общий список видео со всех серверов (SMB, WebDAV, HTTP) с очищенными названиями, постерами TMDB (с учётом ручных исправлений) и плашкой сервера.
- Фоновая рекурсивная индексация с кэшем `library.json` (открывается сразу), ручное обновление и опция «Обновлять при запуске».
- Поиск по всем серверам, сортировка (название/год/дата добавления), фильтр по серверу; воспроизведение с продолжением с места остановки.
- APK меньше: из сборки исключены неиспользуемые таблицы bouncycastle (Picnic) и копии лицензий (release ≈ 5,4 МБ, debugMin ≈ 9,7 МБ).
- Раздел настроек «Библиотека»: глубина, корневые папки, очистка.
- Индекс библиотеки хранится в Room (SQLite) с индексами по серверу/названию/году/дате; старый `library.json` импортируется один раз и удаляется.
- Быстрый поиск через FTS4 (имя файла + очищенное название, префиксный поиск, без учёта регистра и «ё»), задержка ввода 250 мс, сортировка и фильтр в SQL, подгрузка страницами по 200.
- Индексация: файлы сохраняются по мере нахождения, удалённые файлы убираются только после полного успешного обхода; до 3 серверов параллельно, тайм-аут 15 мин на сервер; прогресс (серверы, папки, видео) и кнопка «Остановить».
- Тест производительности на 50 000 записей.
- Тесты: unit-тесты индексатора/запросов, Robolectric-тест экрана, интеграционный тест на трёх локальных серверах.

## [1.0.0] — 2026-10-16
### Добавлено
- UI-тесты Compose на JVM (Robolectric): список серверов, редактирование сервера, браузер файлов с фейковым репозиторием, настройки.
- GitHub Actions: CI (сборка debug, unit-тесты, lint, APK как артефакт) и релизный workflow по тегу `v*` (подписанный APK в черновик GitHub Release).
- Подпись release-сборки из переменных окружения/секретов; без ключа локально собирается неподписанный APK.
- Lint-baseline, lint теперь прерывает сборку при новых ошибках.
### Изменено
- Release-сборка: R8 (minify) + сжатие ресурсов, проверенные keep-правила для smbj/dcerpc/bouncycastle/kotlinx.serialization. Размер APK ≈ 6,6 МБ.
- Версия 1.0.0 (versionCode 10).

## [0.5.0] — Этап 5. Интерфейс
- Поиск по папке, избранное, «Продолжить просмотр», адаптивная/тематическая иконка, все строки UI в ресурсах (ru/en).

## [0.4.0] — Этап 4. Плеер
- Диалог дорожек, перемотка свайпом, полноэкранный режим, PiP, MediaSession-сервис и фоновое аудио; сборка debugMin.

## [0.3.0] — Этап 3. WebDAV и HTTP
- Просмотр WebDAV (PROPFIND, Basic/Digest) и HTTP autoindex, воспроизведение с Range и авторизацией.
- Доверие к самоподписанным HTTPS-сертификатам (pinning SHA-256) для отдельного сервера.

## [0.2.x] — Названия и TMDB, настройки
- Чистые названия из имён файлов, постеры и названия из TMDB с кэшем, ручная коррекция совпадений.
- Экран настроек: воспроизведение, субтитры, сеть, интерфейс, управление, данные.

## [0.2.0] — Этап 2. SMB
- Пул SMB-сессий, таймауты и повторы, упреждающее чтение, выбор общей папки, обработка ошибок.

## [0.1.0] — Этапы 0–1
- Каркас приложения: Compose, навигация, просмотр SMB, плеер Media3 с источником smbj.
- Сохранение серверов (DataStore), шифрование паролей Keystore, редактирование/удаление, проверка соединения.
