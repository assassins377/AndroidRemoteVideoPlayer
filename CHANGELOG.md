# Журнал изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]
### Добавлено
- Экран «Библиотека»: общий список видео со всех серверов (SMB, WebDAV, HTTP) с очищенными названиями, постерами TMDB (с учётом ручных исправлений) и плашкой сервера.
- Фоновая рекурсивная индексация с кэшем `library.json` (открывается сразу), ручное обновление и опция «Обновлять при запуске».
- Поиск по всем серверам, сортировка (название/год/дата добавления), фильтр по серверу; воспроизведение с продолжением с места остановки.
- Раздел настроек «Библиотека»: глубина, корневые папки, очистка.
- Тесты: unit-тесты индексатора/запросов, Robolectric-тест экрана, интеграционный тест на трёх локальных серверах.

## [1.0.0] — 2026-10-16
### Добавлено
- UI-тесты Compose на JVM (Robolectric): список серверов, редактирование сервера, браузер файлов с фейковым репозиторием, настройки.
- GitHub Actions: CI (сборка debug, unit-тесты, lint, APK как артефакт) и релизный workflow по тегу `v*` (подписанный APK в черновик GitHub Release).
- Подпись release-сборки из переменных окружения/секретов; без ключа локально собирается неподписанный APK.
- Lint-baseline, lint теперь прерывает сборку при новых ошибках.
### Изменено
- Release-сборка: R8 (minify) + сжатие ресурсов, проверенные keep-правила для smbj/dcerpc/bouncycastle/kotlinx.serialization. Размер APK ≈ 6,6 МБ.
- Версия 1.0.0 (versionCode 10).

## [0.5.0] — Этап 5. Интерфейс
- Поиск по папке, избранное, «Продолжить просмотр», адаптивная/тематическая иконка, все строки UI в ресурсах (ru/en).

## [0.4.0] — Этап 4. Плеер
- Диалог дорожек, перемотка свайпом, полноэкранный режим, PiP, MediaSession-сервис и фоновое аудио; сборка debugMin.

## [0.3.0] — Этап 3. WebDAV и HTTP
- Просмотр WebDAV (PROPFIND, Basic/Digest) и HTTP autoindex, воспроизведение с Range и авторизацией.
- Доверие к самоподписанным HTTPS-сертификатам (pinning SHA-256) для отдельного сервера.

## [0.2.x] — Названия и TMDB, настройки
- Чистые названия из имён файлов, постеры и названия из TMDB с кэшем, ручная коррекция совпадений.
- Экран настроек: воспроизведение, субтитры, сеть, интерфейс, управление, данные.

## [0.2.0] — Этап 2. SMB
- Пул SMB-сессий, таймауты и повторы, упреждающее чтение, выбор общей папки, обработка ошибок.

## [0.1.0] — Этапы 0–1
- Каркас приложения: Compose, навигация, просмотр SMB, плеер Media3 с источником smbj.
- Сохранение серверов (DataStore), шифрование паролей Keystore, редактирование/удаление, проверка соединения.
