# План разработки AndroidRemoteVideoPlayer

## Этап 0. Каркас (готово)
- Gradle Kotlin DSL + version catalog, модуль `app`, Compose + Material 3, Navigation Compose.
- Экраны: список серверов, добавление сервера, файловый браузер, плеер.
- SMB через smbj (листинг + `SmbDataSource` для Media3 с перемоткой), HTTP по прямой ссылке, заглушка WebDAV.

## Этап 1. Хранение серверов и безопасность
- Сохранение списка серверов (DataStore или Room) вместо памяти.
- Пароли в EncryptedSharedPreferences / Android Keystore; убрать пароль из URI плеера (передавать id сервера).
- Редактирование серверов, проверка подключения при сохранении.

## Этап 2. Надёжный SMB
- Переиспользование соединения/сессии smbj (пул), таймауты, повторные попытки.
- Буферизация чтения (read-ahead) для плавного воспроизведения больших MKV.
- Список общих папок хоста (выбор share), обработка ошибок авторизации.

## Этап 3. WebDAV и HTTP
- Подключить sardine-android (JitPack), листинг через PROPFIND, воспроизведение через HTTP DataSource с Basic-авторизацией.
- HTTP: разбор autoindex-страниц Apache/nginx для просмотра каталогов.

## Этап 4. Плеер
- Внешние субтитры (.srt/.ass/.vtt рядом с видео), выбор дорожек аудио/субтитров.
- Скорость (есть), жесты: перемотка свайпом, громкость/яркость.
- Запоминание позиции, полноэкранный режим и поворот, Picture-in-Picture, фоновое аудио (MediaSession).

## Этап 5. UI/UX
- Переключатель тёмной/светлой темы в настройках, сортировка и поиск по файлам, недавние/избранное.
- Превью/миниатюры, иконка приложения, локализация ru/en.

## Этап 6. Качество и релиз
- Unit-тесты ViewModel и репозиториев, UI-тесты Compose.
- CI в GitHub Actions (assembleDebug + тесты), R8/ProGuard для release, подпись, релиз APK на GitHub.
