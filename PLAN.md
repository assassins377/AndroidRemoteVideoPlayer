# План разработки AndroidRemoteVideoPlayer

## Этап 0. Каркас (готово)
- Gradle Kotlin DSL + version catalog, модуль `app`, Compose + Material 3, Navigation Compose.
- Экраны: список серверов, добавление сервера, файловый браузер, плеер.
- SMB через smbj (листинг + `SmbDataSource` для Media3 с перемоткой), HTTP по прямой ссылке, заглушка WebDAV.

## Этап 1. Хранение серверов и безопасность (готово)
- [x] Список серверов сохраняется в DataStore (JSON через kotlinx.serialization).
- [x] Пароли шифруются AES-256-GCM ключом из Android Keystore (без устаревшей security-crypto).
- [x] Ссылка воспроизведения `rvp-smb://<id сервера>/<путь>` — без логина и пароля; `SmbDataSource` берёт данные по id.
- [x] Редактирование и удаление серверов, кнопка «Проверить подключение» (SMB и HTTP).
- [x] Unit-тесты: SmbUri, сериализация серверов.

## Этап 2. Надёжный SMB (готово)
- [x] Пул SMB-сессий по id сервера (`SmbPool`): одно соединение/сессия/share на сервер, пересоздаётся при смене настроек или обрыве.
- [x] Таймауты smbj (запрос 20 с, сокет 30 с) и повторы с экспоненциальной задержкой (`RetryPolicy`, 3 попытки, 300 мс → 3 с).
- [x] Read-ahead блоками по 1 МиБ в `SmbDataSource`, переоткрытие файла при обрыве; увеличенные буферы ExoPlayer (`DefaultLoadControl`: 30–120 с).
- [x] Выбор общей папки: список через smbj-rpc (MS-SRVS NetShareEnum), при ошибке — ручной ввод.
- [x] Понятные ошибки (неверный пароль, нет доступа, не найдено, сервер недоступен, таймаут) в браузере, плеере и проверке подключения; кнопки «Повторить».
- [x] Unit-тесты: повторы/backoff, классификация ошибок, read-ahead буфер.

## Этап 3. WebDAV и HTTP
- Подключить sardine-android (JitPack), листинг через PROPFIND, воспроизведение через HTTP DataSource с Basic-авторизацией.
- HTTP: разбор autoindex-страниц Apache/nginx для просмотра каталогов.

## Настройки (ветка `settings`, готово, кроме отмеченного)
- Экран настроек (DataStore), строки ru + en; вход из верхней панели списка серверов.
- Воспроизведение: скорость по умолчанию, шаг перемотки 10/15/30 с, продолжение с места остановки (позиция по ключу файла, LRU 500), автоплей следующего видео в папке (SMB), язык аудио, HW/SW декодирование (порядок MediaCodecSelector).
- Субтитры: язык, автоподгрузка внешних .srt/.ass/.vtt с тем же именем (SMB), размер, цвет, фон.
  - **Не сделано:** сдвиг субтитров по времени — в Media3 нет штатного API; нужен свой парсер/обёртка Cue.
- Сеть: макс. буфер (LoadControl), блок упреждающего чтения, таймаут и число попыток (SmbPool/Retry), версия SMB 2/3/авто и шифрование SMB3 (SmbConfig). Смена сетевых настроек пересоздаёт SMB-клиент.
- Интерфейс: тема система/светлая/тёмная + AMOLED, сортировка имя/дата/размер, скрытые файлы, список/сетка (в сетке иконки-заглушки, не кадры видео), язык ru/en (LocaleManager на 13+, контекст на старых).
- Управление: свайпы громкость/яркость, двойное касание для перемотки, PiP при сворачивании, блокировка поворота.
- Данные: очистка кэша и истории, экспорт/импорт серверов в JSON без паролей (SAF).

## Названия и постеры (ветка `titles-tmdb`, готово)
- Разбор имён файлов: расширение, точки/подчёркивания, год (последний «годоподобный» токен), качество 720p/1080p/4K, удаление тегов источника/кодека, серии SxxEyy / 1x02 / «2 сезон 5 серия». Показ «Название (Год)», подзаголовок «качество · размер», размер Б/КБ/МБ/ГБ.
- TMDB: ключ v3 или токен v4 (шифруется Keystore), переключатель, язык ru-RU/en-US по языку приложения; поиск movie/tv по названию+году (повтор без года); кэш JSON-файлом с TTL 30 дней (не найдено — 1 день); не более 3 запросов одновременно, дедупликация, задержка 350 мс перед запросом при прокрутке. Постеры через Coil в списке и сетке, карточка с описанием по долгому нажатию.
- Остаток: постеры для папок сериалов, ручная корректировка совпадения, выбор из нескольких результатов.

## Этап 4. Плеер (остаток)
