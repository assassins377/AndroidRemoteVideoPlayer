# Remote Video Player — руководство пользователя

🇬🇧 [English version](GUIDE.en.md)

Remote Video Player — Android-плеер для видео, лежащих на компьютере или NAS в домашней сети. Поддерживаются SMB (общие папки Windows, Samba, Synology/QNAP), WebDAV и HTTP (списки файлов nginx/Apache или прямые ссылки). Названия кнопок и настроек ниже совпадают с интерфейсом приложения на русском языке.

## 1. Установка

Нужен Android 8.0 или новее.

1. Скачайте файл `AndroidRemoteVideoPlayer-<версия>-release.apk` со страницы [Releases](https://github.com/assassins377/AndroidRemoteVideoPlayer/releases).
2. Откройте скачанный файл. Android попросит разрешить установку из неизвестных источников для приложения, через которое вы открыли APK (браузера или файлового менеджера). Нажмите **Настройки**, включите **Разрешить из этого источника** и вернитесь назад. Названия пунктов зависят от производителя телефона.
3. Нажмите **Установить**. Play Защита может предупредить о неизвестном разработчике — выберите «Всё равно установить».

Обновление: установите новый APK поверх старого. Серверы и настройки сохранятся, потому что все релизы подписаны одним ключом.

## 2. Первый запуск

Главный экран называется **Серверы**. Если серверов ещё нет, на нём написано: «Нет серверов. Нажмите +, чтобы добавить SMB, HTTP или WebDAV.»

- **+** (кнопка внизу справа) — добавить сервер.
- **★** (вверху) — **Избранное**.
- **⚙** (вверху) — **Настройки**.
- Нажатие на сервер открывает его папки. Значок карандаша (**Изменить**) открывает настройки сервера.

Язык приложения следует за языком системы. Его можно поменять в **Настройки → Интерфейс → Язык приложения**.

## 3. Добавление сервера: SMB

Нажмите **+**. Откроется экран **Новый сервер**. Вверху выберите тип **SMB** и заполните поля:

| Поле | Что вводить |
|---|---|
| **Название** | Любое имя, например «NAS в гостиной» |
| **Хост (192.168.1.10)** | IP-адрес или сетевое имя компьютера/NAS, без `smb://` и без слэшей. Используется стандартный порт 445 |
| **Общая папка (share)** | Имя общей папки, например `video`. Обязательное поле |
| **Пользователь (пусто = гость)** | Логин на сервере. Оставьте пустым для гостевого доступа |
| **Пароль** | Пароль пользователя |
| **Домен (необязательно)** | Домен Windows или рабочая группа. Обычно оставляют пустым |

Когда хост введён, кнопка **Найти папки на сервере** запрашивает список общих папок. Выберите нужную в списке. Возможные результаты:
- «Папок не найдено — введите вручную» — сервер не отдал ни одной папки;
- «Не удалось получить список: … . Введите вручную.» — запрос не удался.

В обоих случаях введите имя папки вручную.

Нажмите **Проверить подключение**, а затем **Сохранить**. **Сохранить** становится активной, когда заполнены хост и общая папка.

### Как узнать IP-адрес
- **Windows**: `Win+R` → `cmd` → `ipconfig`. Нужна строка «IPv4-адрес».
- **macOS/Linux**: `ip addr` или «Системные настройки → Сеть».
- **Synology**: DSM → Панель управления → Сеть → Сетевой интерфейс, или find.synology.com.
- **QNAP**: Qfinder Pro или Панель управления → Сеть и виртуальный коммутатор.
- **Роутер**: список подключённых устройств (DHCP-клиенты).

Чтобы IP не менялся, закрепите его за устройством в DHCP роутера.

### Windows
1. Правый клик по папке → **Свойства → Доступ → Расширенная настройка** → «Открыть общий доступ к этой папке». Запомните имя общего ресурса.
2. В **Разрешениях** и на вкладке **Безопасность** дайте вашему пользователю право «Чтение».
3. Для учётной записи Microsoft логин — это адрес e-mail, а пароль — пароль от учётной записи Microsoft, а не PIN.
4. Профиль сети должен быть **Частная**, иначе брандмауэр блокирует SMB.

### Samba (Linux)
Пример раздела в `/etc/samba/smb.conf`:
```ini
[video]
   path = /srv/video
   read only = yes
   valid users = alice
```
Задайте пароль командой `sudo smbpasswd -a alice` и перезапустите `smbd`. Приложение работает по SMB2/SMB3. Старый SMB1 не поддерживается, поэтому проверьте, что нет `server max protocol = NT1`.

### Synology (DSM)
1. **Панель управления → Файловые службы → SMB**: включите службу SMB. В **Дополнительных настройках** установите минимальный протокол **SMB2** (или SMB2 и Large MTU), максимальный — **SMB3**.
2. **Панель управления → Пользователь**: создайте пользователя или используйте существующего.
3. **Общая папка → Изменить → Разрешения**: дайте пользователю право «Только чтение» или «Чтение/запись».
4. В приложении в поле **Общая папка (share)** укажите имя общей папки, например `video`, без `/volume1`.

### QNAP (QTS)
1. **Панель управления → Сетевые и файловые службы → Win/Mac/NFS/WebDAV → Сеть Microsoft**: включите службу файлов для сети Microsoft. В **Дополнительных параметрах** выберите максимальную версию SMB3, минимальную — SMB2.
2. **Привилегии → Общие папки → Изменить права доступа**: дайте пользователю право на чтение.

### Версия SMB и шифрование
Эти параметры общие для всех SMB-серверов. Они находятся в **Настройки → Сеть и буфер**:
- **Версия SMB**: **Авто** (сначала SMB 3.1.1, при неудаче более старые версии вплоть до SMB 2.0.2), **SMB2** или **SMB3**. Ручной выбор помогает со старыми или капризными NAS.
- **Шифрование SMB3**: включите, если на сервере требуется шифрование. Например, на Synology это «Принудительное шифрование SMB3». Шифрование немного нагружает телефон.

## 4. Добавление сервера: WebDAV

Выберите тип **WEBDAV** и заполните поля:
- **Название**;
- **URL (http://...)** — полный адрес WebDAV-папки (форматы ниже);
- **Пользователь (пусто = гость)** и **Пароль**.

Приложение само определяет нужную авторизацию: Basic или Digest.

| Сервер | Формат URL |
|---|---|
| Synology, пакет **WebDAV Server** | `http://192.168.1.10:5005/video` или `https://192.168.1.10:5006/video` |
| QNAP (WebDAV в «Win/Mac/NFS/WebDAV») | `http://192.168.1.20:8080/video` (HTTPS: `https://…:443/video`). Номер порта указан в настройках QTS |
| Nextcloud | `https://cloud.example.com/remote.php/dav/files/ЛОГИН/Видео` |
| Apache/nginx/wsgidav | Адрес настроенной вами папки, например `http://host:8081/dav` |

**Synology.** Установите пакет **WebDAV Server** из Центра пакетов. Включите HTTP (5005) и/или HTTPS (5006). Пользователь должен иметь права на общую папку. Если в DSM есть отдельное разрешение приложения WebDAV, оно тоже должно быть разрешено.

**QNAP.** **Панель управления → Win/Mac/NFS/WebDAV → WebDAV**: включите WebDAV и выберите режим прав «Права общих папок» или «Права WebDAV».

**Nextcloud.** Для аккаунта с двухфакторной аутентификацией создайте пароль приложения: **Настройки → Безопасность → Пароли приложений**.

### Самоподписанный HTTPS-сертификат
Если сервер использует сертификат, которому Android не доверяет, после **Проверить подключение** (или при открытии папки) появится карточка с текстом:
- «Сервер использует самоподписанный сертификат, которому система не доверяет.» (или «Сервер использует сертификат, которому система не доверяет.»);
- **Кому выдан**, **Кем выдан**, **Действителен**, **SHA-256** — отпечаток сертификата;
- «Сверьте отпечаток с настройками сервера (NAS) перед тем, как доверять.»

Сравните SHA-256 с отпечатком в настройках NAS или с выводом `openssl x509 -noout -fingerprint -sha256 -in cert.pem`. Если совпадает, нажмите **Доверять этому сертификату**.

После доверия в настройках сервера отображается строка «Доверенный сертификат (SHA-256): XX:XX:…». Кнопка **Забыть сертификат** удаляет доверие. Изменения в этой части вступают в силу после «Сохранить».

**Смена сертификата.** Если сертификат сервера изменился и больше не совпадает с сохранённым, приложение покажет предупреждение: «Сертификат изменился! Если вы не обновляли сертификат на сервере, не доверяйте ему.» Кнопка в этой карточке называется **Доверять новому сертификату**. Нажимайте её, только если вы сами обновляли сертификат (например, он перевыпустился на NAS). Иначе возможна подмена сервера.

Доверие хранится отдельно для каждого сервера и действует только для него.

## 5. Добавление сервера: HTTP

Выберите тип **HTTP**. В поле **URL (http://...)** можно указать:
- **Список файлов (autoindex)**, например `http://192.168.1.10:8080/video/`. Приложение разбирает страницы nginx `autoindex on;` и Apache `Options +Indexes` и показывает папки, видео и файлы субтитров.
- **Прямую ссылку на видео**, например `http://host/movies/Film.mkv`. Тогда в браузере приложения будет один файл.

Если сайт закрыт паролем (Basic или Digest), заполните **Пользователь** и **Пароль**. HTTPS с самоподписанным сертификатом работает так же, как у WebDAV (см. выше).

Пример для nginx:
```nginx
location /video/ {
    alias /srv/video/;
    autoindex on;
}
```
Пример для Apache:
```apache
<Directory "/srv/video">
    Options +Indexes
    Require all granted
</Directory>
```

## 6. Проверка подключения и сообщения об ошибках

Кнопка **Проверить подключение** показывает либо «Подключение успешно», либо «Ошибка: <сообщение>». Те же сообщения появляются в браузере папок вместе с кнопкой **Повторить**.

| Сообщение | Что значит и что делать |
|---|---|
| Неверный логин или пароль | Неправильные учётные данные. Исправьте их в настройках сервера: в браузере показывается подсказка «Измените логин/пароль в настройках сервера.» |
| Нет доступа к папке или файлу | Пользователь вошёл, но не имеет прав на папку. Выдайте право чтения на сервере |
| Папка, файл или общий ресурс не найдены | Неверное имя общей папки или путь (SMB), либо HTTP 404/410. Проверьте имя или воспользуйтесь «Найти папки на сервере» |
| Сервер не найден (проверьте адрес) | Имя хоста не распознаётся. Укажите IP-адрес вместо имени |
| Сервер недоступен (выключен или другая сеть) | Нет связи: сервер выключен, телефон в другой сети или в мобильном интернете, порт закрыт брандмауэром |
| Превышено время ожидания ответа сервера | Сервер не ответил вовремя: спящий NAS или слабый Wi-Fi. Увеличьте «Таймаут подключения» |
| Ошибка сети, соединение прервано | Соединение оборвалось. Проверьте Wi-Fi |
| Сертификат сервера не подтверждён (самоподписанный или неизвестный центр) | Самоподписанный HTTPS. Доверьтесь сертификату через карточку (раздел 4) |
| Внимание: сертификат сервера изменился и не совпадает с сохранённым. Возможна подмена сервера | Сертификат отличается от сохранённого. Читайте «Смена сертификата» в разделе 4 |
| Сертификат выдан для другого имени сервера | Сертификат выдан на другое имя. Подключайтесь по имени из сертификата |
| Не страница со списком файлов (…) | По HTTP-адресу пришла не HTML-страница со списком файлов. Включите autoindex или укажите прямую ссылку на видео |
| Не WebDAV-сервер (HTTP …) | Адрес не отвечает как WebDAV. Проверьте URL (для Nextcloud нужен `/remote.php/dav/files/…`) и включён ли WebDAV |
| Неизвестная ошибка | Другая ошибка. Попробуйте **Повторить**, проверьте настройки |
| Сервер не найден | Сервер был удалён (например, при открытии старой ссылки) |
| Ошибка воспроизведения: … | Ошибка в плеере. Кнопки: **Повторить** и **Назад** |

Иногда в браузере появляется «… Откройте папку заново, чтобы проверить сертификат.». Вернитесь назад и откройте папку снова — появится карточка сертификата.

## 7. Постеры и названия (TMDB)

Приложение умеет показывать вместо имён файлов чистые названия, например «The Matrix (1999)» с подписью «1080p · 4,2 ГБ». Если подключить The Movie Database (TMDB), к ним добавятся постеры и локализованные названия.

1. Зарегистрируйтесь на [themoviedb.org](https://www.themoviedb.org/).
2. Откройте профиль → **Settings → API** и создайте ключ (тип Developer). Подойдёт как **API Key (v3)**, так и **API Read Access Token (v4)**.
3. В приложении: **Настройки → Постеры и названия (TMDB)**. Вставьте ключ в поле **Ключ API TMDB (v3) или токен (v4)** и нажмите **Сохранить ключ**. Строка состояния сменится на «Ключ сохранён (зашифрован)».
4. Включите **Загружать постеры и названия**.

Язык названий совпадает с языком приложения. **Удалить ключ** удаляет сохранённый ключ.

Связанные ошибки: «TMDB: неверный ключ API» и «Ключ TMDB не задан».

**Неверное совпадение.** Долгое нажатие на файл открывает окно **Подробнее**. Там есть кнопка **Не тот фильм?**. В поиске можно задать **Название**, **Год**, выбрать **Фильм** или **Сериал** и нажать **Найти**. Другие варианты:
- **Показывать без TMDB** — отключить TMDB для этого файла;
- **Вернуть автоматический выбор** — отменить ручной выбор.

Пометки «Выбрано вручную» и «TMDB отключён для этого файла» показывают текущее состояние.

**VPN.** В некоторых странах и у некоторых провайдеров api.themoviedb.org и image.tmdb.org недоступны или работают медленно. Если постеры не загружаются, а ключ верный, включите VPN или смените DNS. Сам просмотр видео в локальной сети от TMDB не зависит.

## 8. Настройки

Откройте **⚙ Настройки** на экране **Серверы**.

### Воспроизведение
- **Скорость по умолчанию**: 0.5x–2.0x.
- **Шаг перемотки**: 10, 15 или 30 с. Используется при двойном касании.
- **Продолжать с места остановки**: запоминает позицию и продолжает с неё.
- **Автовоспроизведение следующего видео**: после окончания запускает следующий файл из той же папки.
- **Язык аудио**: предпочитаемая дорожка — Любой, ru, en, ja, uk, de, fr.
- **Декодирование**: **Авто**, **Аппаратное** или **Программное**. Если видео не играет или показывает артефакты, попробуйте другой режим.

### Субтитры
- **Язык субтитров**: предпочитаемый язык.
- **Подгружать внешние .srt/.ass/.vtt**: автоматически подключает файлы субтитров рядом с видео (см. раздел 9).
- **Размер шрифта**: 14–34 sp.
- **Цвет текста**: Белый, Жёлтый или Зелёный.
- **Фон**: Нет, Полупрозрачный или Чёрный.

Сдвиг субтитров по времени пока не поддерживается (ограничение Media3).

### Сеть и буфер
- **Буфер (максимум)**: 30, 60, 120 или 300 с видео заранее.
- **Блок чтения**: 256–4096 КБ (размер блока упреждающего чтения).
- **Таймаут подключения**: 5–60 с.
- **Число попыток**: 1, 2, 3 или 5 повторов при сбоях сети.
- **Версия SMB** и **Шифрование SMB3**: см. раздел 3.

### Интерфейс
- **Тема**: Системная, Светлая или Тёмная. **Чёрный фон (AMOLED)** включает полностью чёрный фон.
- **Сортировка**: Имя, Дата или Размер.
- **Показывать скрытые файлы**: показывает файлы, начинающиеся с точки, и скрытые файлы SMB.
- **Сетка вместо списка**: плитки с постерами вместо списка.
- **Язык приложения**: Системный, Русский или English.

### Управление
- **Жесты: громкость и яркость**: вертикальный свайп слева меняет яркость, справа — громкость.
- **Двойное касание для перемотки**.
- **Картинка в картинке при сворачивании**.
- **Блокировать поворот в плеере**.
- **Горизонтальный свайп — перемотка**.
- **Звук в фоне (при сворачивании)**.

### Постеры и названия (TMDB)
См. раздел 7.

### Библиотека
- **Обновлять библиотеку при запуске** — при каждом запуске приложения библиотека обновляется в фоне (выключено по умолчанию).
- **Глубина поиска по папкам** — на сколько уровней вложенных папок заходить (по умолчанию 5).
- **Корневые папки** — какие папки индексировать, по одной на строку (например `Movies`). Пусто — весь сервер. Применяется ко всем серверам; если папки на сервере нет, она пропускается. Кнопка **Сохранить**, рядом — **Обновить библиотеку**.
- **Очистить библиотеку** — удалить сохранённый список (файлы на сервере не трогаются).

### Данные
- **Очистить кэш**: удаляет временные файлы и кэш TMDB, закрывает SMB-соединения.
- **Очистить историю просмотра**: стирает сохранённые позиции и «Продолжить просмотр».
- **Экспорт серверов (без паролей)** и **Импорт серверов**: см. раздел 11.

## 9. Плеер

Видео открывается нажатием на файл.

- **Касание** по центру показывает или скрывает панель управления: пауза, полоса перемотки.
- **Двойное касание** справа перематывает вперёд, слева — назад на «Шаг перемотки». На экране появляется подсказка, например «+10 с».
- **Горизонтальный свайп** перематывает. Подсказка показывает сдвиг и целевое время.
- **Вертикальный свайп**: слева — яркость («Яркость N%»), справа — громкость («Громкость N%»).
- Кнопка скорости вверху справа (например **1.0x**) — меню скоростей 0.5x–2.0x.
- Кнопка **Дорожки** появляется, если есть несколько аудиодорожек или субтитры. В окне есть разделы **Аудио** и **Субтитры**. Пункт **Выключены** отключает субтитры. **Закрыть** закрывает окно.
- **Картинка в картинке**: если включена «Картинка в картинке при сворачивании», при нажатии «Домой» видео продолжается в маленьком окне.
- **Звук в фоне**: если включён «Звук в фоне (при сворачивании)», звук продолжает играть после сворачивания. В шторке уведомлений и на экране блокировки появляются кнопки управления.

### Внешние субтитры
Положите файл субтитров в ту же папку, что и видео, с тем же именем:
```
Film.mkv
Film.srt          ← без языка
Film.ru.srt       ← русский
Film.eng.forced.ass
```
Поддерживаются `.srt`, `.ass`, `.ssa` и `.vtt`. Код языка после имени (`ru`, `en`, `eng`…) используется для выбора дорожки по «Язык субтитров». Должна быть включена настройка «Подгружать внешние .srt/.ass/.vtt». Субтитры подключаются для SMB, WebDAV и HTTP-списков файлов. Для прямой HTTP-ссылки они не подключаются.

## 10. Избранное, «Продолжить просмотр», поиск

- **Избранное**: в списке файлов нажмите на звёздочку справа: **В избранное** или **Убрать из избранного**. Отмечать можно и файлы, и папки. Список открывается кнопкой **★** на экране **Серверы**. Если он пуст: «Пока пусто. Отмечайте файлы и папки звёздочкой.» В режиме «Сетка вместо списка» звёздочки нет — переключитесь на список.
- **Продолжить просмотр**: на экране **Серверы** над списком серверов есть лента недосмотренных видео с полосой прогресса. Нажмите на видео, чтобы продолжить. Крестик (**Убрать из истории**) удаляет его из ленты.
- **Поиск**: в папке нажмите значок лупы (**Поиск**) и вводите текст в поле «Поиск в папке». Поиск ищет только в текущей папке. Если совпадений нет: «Ничего не найдено». Повторное нажатие (✕) закрывает поиск.

### Библиотека: все серверы вместе

Можно подключить сразу несколько серверов разных типов (SMB, WebDAV, HTTP) — каждый добавляется отдельно. Кнопка **Библиотека** (значок с плёнками) на экране **Серверы** открывает общий список видео со всех серверов.

- Первый раз нажмите **Обновить библиотеку** (стрелка вверху). Приложение в фоне обходит папки всех серверов и запоминает найденные видео. Список сохраняется на телефоне, поэтому потом открывается сразу, даже без сети (воспроизведение, конечно, требует доступа к серверу).
- Каждое видео показано с очищенным названием и постером TMDB (если TMDB включён), справа — плашка с именем сервера. Нажатие на плашку оставляет в списке только этот сервер.
- **Поиск по всем серверам** — по названию, сразу по всей библиотеке.
- Сортировка: **Название**, **Год**, **Дата добавления**. Фильтр: **Все серверы** или один сервер.
- Нажатие на видео запускает его в обычном плеере, с продолжением с места остановки.
- Во время обновления видно, сколько серверов уже готово, и по каждому — сколько папок пройдено и видео найдено. Найденное сразу появляется в списке. Кнопка **Остановить** (✕) прерывает обновление; уже найденное остаётся. Одновременно обходится до 3 серверов; если сервер не ответил за 15 минут, по нему будет ошибка «timeout».
- Поиск срабатывает через четверть секунды после ввода и ищет по началу слов (например, «матр» найдёт «Матрица»), без учёта регистра и «ё». Большие библиотеки (десятки тысяч файлов) подгружаются по мере прокрутки.
- Если какой-то сервер недоступен, под строкой поиска появится ошибка с его именем, а его старые записи останутся в библиотеке.
- Новые файлы появятся только после обновления (кнопкой или автоматически при запуске — см. настройки).

### Сериалы
В **Библиотеке** выберите **Сериалы**: серии одного сериала собраны в одну карточку (сезонов/серий). Распознаются имена вида `Show.S01E02`, `Show.1x02`, «1 сезон 2 серия», а также папки `Сериал/Season 2/E05.mkv` и `Сериал/Сезон 1/Серия 04.mkv`. Внутри — вкладки сезонов и список серий с полосой прогресса.
- Кружок слева (или долгое нажатие) — отметить серию просмотренной / снять отметку. Видео, досмотренное на 90 %, отмечается автоматически.
- Когда серия заканчивается (и включено «Автовоспроизведение следующего»), появляется карточка «Следующая серия через N с» с кнопками **Смотреть сейчас** и **Отмена**. Следующая серия берётся из библиотеки по порядку сезонов/серий, иначе — следующий файл в папке.
- После обновления приложения нажмите **Обновить библиотеку** один раз: формат базы изменился.

### Задержка субтитров
В плеере нажмите **Дорожки**. Если к видео подключены внешние субтитры (файл .srt/.vtt/.ass рядом с видео), внизу есть «Задержка внешних субтитров» и кнопки −0,5 / −0,1 / +0,1 / +0,5 с. «+» — субтитры появляются позже. Значение запоминается для этого файла; **Сбросить задержку** возвращает 0. При смене задержки видео на секунду перезагружается с того же места.
Ограничения: встроенные в MKV субтитры и звук сдвигать нельзя (плеер Media3 этого не поддерживает).

### Кадры из видео
Если TMDB выключен или не нашёл фильм, вместо значка плёнки показывается кадр из самого видео (примерно 10 % от начала). Приложение читает только нужные куски файла по сети, по одному видео за раз, и сохраняет картинку в кэш. Отключить: **Настройки → Постеры и названия → Кадр из видео, если нет постера**. «Очистить кэш» удаляет и кадры.

### Карточка фильма
Долгое нажатие на видео (в папке, а с версии с библиотечным меню — и в библиотеке) открывает карточку: постер, рейтинг, слоган, жанры и длительность (для сериалов — число сезонов), описание, лента актёров с фото и кнопка **▶ Трейлер (YouTube)**, если трейлер есть на TMDB. Нужен ключ TMDB.

### Android TV
Установите APK на телевизор/приставку (например, через «Send files to TV» или adb). Приложение появится в лаунчере TV. Навигация — стрелками пульта и кнопкой OK; на TV список файлов всегда показывается сеткой, выбранная карточка обведена рамкой. В плеере: ←/→ — перемотка на шаг из настроек, OK — пауза/продолжить, ↑/↓ — показать панель управления (дальше стрелками по кнопкам), кнопки ⏪/⏩/⏯ на пульте тоже работают. Жесты и PiP на TV не используются.

### Трансляция на телевизор (Chromecast / DLNA)
В плеере нажмите **На ТВ**. Приложение ищет Chromecast (нужны сервисы Google Play) и DLNA-телевизоры (Samsung, LG, Sony и др.) в той же Wi-Fi сети. Выберите устройство — видео начнёт играть на ТВ с текущего места, а на телефоне встанет на паузу. Вверху появится «Воспроизводится на: …» с кнопками ⏯ и **Остановить**.
Как это работает: телефон сам раздаёт видео по локальной сети (встроенный мини-сервер), поэтому подходят любые источники, включая SMB и WebDAV с паролем. Телефон должен оставаться включённым и в той же сети.
Ограничения: Chromecast воспроизводит только форматы, которые поддерживает сам (обычно MP4/H.264, WebM; MKV — не всегда, звук AC3/DTS часто не идёт). Перемотка и пауза — с пульта ТВ/из приложения Google Home; внешние субтитры не передаются.

## 11. Экспорт и импорт серверов

- **Настройки → Данные → Экспорт серверов (без паролей)** сохраняет файл `remoteplayer-servers.json` в выбранное место. Пароли в файл **не** попадают.
- **Импорт серверов**: выберите такой файл. Появится сообщение «Импортировано серверов: N. Введите пароли заново.» Затем откройте каждый сервер и введите пароль. Если файл не подходит: «Не удалось импортировать файл».

## 12. Решение проблем (FAQ)

**Большие MKV (4K, высокий битрейт) подтормаживают.**
- Увеличьте **Буфер (максимум)** до 120–300 с и **Блок чтения** до 2048–4096 КБ.
- Используйте Wi-Fi 5 ГГц (802.11ac/ax) и держитесь ближе к роутеру. Для 4K-ремуксов нужно 80–100+ Мбит/с реальной скорости.
- По возможности подключите NAS к роутеру кабелем.
- Попробуйте **Декодирование → Программное** (или наоборот **Аппаратное**), если тормозит картинка при нормальной сети.
- Для SMB выключите **Шифрование SMB3**, если сервер его не требует.

**Не видно файлов.** Отображаются только папки, видео (`.mp4 .mkv .avi .mov .webm .m4v .ts .wmv`) и субтитры. Скрытые файлы показываются после включения «Показывать скрытые файлы».

**SMB не подключается.**
- Проверьте, что включены SMB2/SMB3 (SMB1 не поддерживается) и что порт 445 не закрыт.
- Попробуйте **Версия SMB → SMB2** или **SMB3**.
- Укажите IP-адрес вместо имени.

**Работает дома, но не работает вне дома.** Сервер доступен только в локальной сети. Снаружи нужен VPN до домашней сети, например WireGuard или Tailscale.

**Нет звука в фоне / нет PiP.** Включите соответствующие пункты в **Настройки → Управление**. На некоторых прошивках нужно также разрешить работу в фоне в настройках батареи Android.

**Пропали позиции просмотра.** Их удаляет **Очистить историю просмотра**. Ещё проверьте, включено ли «Продолжать с места остановки».

**Постеры не грузятся.** Проверьте ключ и включённость TMDB (раздел 7), а также доступ к TMDB (VPN).

## 13. Конфиденциальность

- Пароли серверов и ключ TMDB хранятся на устройстве в зашифрованном виде (ключ шифрования находится в Android Keystore).
- Приложение не собирает статистику и не имеет аналитики или рекламы. Оно подключается только к вашим серверам и, если включено «Загружать постеры и названия», к TMDB (api.themoviedb.org, image.tmdb.org). В TMDB отправляются только названия и годы, распознанные из имён файлов.
- Экспорт серверов не содержит паролей.
